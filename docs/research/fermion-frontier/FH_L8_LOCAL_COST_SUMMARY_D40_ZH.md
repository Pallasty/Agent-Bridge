# FH-L8 D40：有界局部成本包络

D40 内容固定绑定 D32/D33、D35/D36、D38/D39 的冻结结果：8、16、32 个代表元均有结构复放；其中固定 32-target 的 D38/D39 结构摘要完全一致（`d87e09…6376`）。六次观测的峰值 RSS 范围是 40,308–40,772 KiB。

这不是用样本推断 full-53 的成本。D40 只预注册下一门局部实验的准入条件：固定 64 个代表元、至多 3 次选择 collector、至多 68 次科学动作、进程 RSS 上限 65,536 KiB，并且必须完成独立结构复放。若其中任一条件不满足，D41 不得宣称通过此包络。

校准器对所有输入结果文件执行 SHA-256 内容固定；它不读取 packed-q3，不执行 full shard，也不提供 full-53 授权或外推。
