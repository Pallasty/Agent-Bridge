# FH-L8 D60 外部介质与启动证据收件门（D92）

## 当前收件结果

D92 对主机做了只读盘点。当前唯一独立控制器介质仍是 63.86 GB 的 `mmcblk0`，且桌面
自动挂载在 `/run/media/pallasting/SD_F2FS`。没有第二块可覆盖的 64 GB 介质；没有满足整盘
镜像加 20 GB 余量的安全备份目标；没有固件 SD 启动证明。Ubuntu/NVMe 回退项仍只是回退，
不是 SD 启动证明。

## 必须由 owner 提供

1. 明确可覆盖的新介质（至少 64 GB），或现有数据处置、完整镜像 SHA-256 与恢复抽样；
2. 稳定 `/dev/disk/by-id` 身份和容量收据；
3. 固件从 SD 控制器启动的非破坏性证明；
4. 在执行门前确认当前桌面已卸载 `mmcblk0p1`。

D92 不自动卸载当前卡，因为该挂载可能属于 owner 的桌面会话。没有这些输入，不授权
分区、格式化、备份写、EFI/固件变更、重启、D82R 或测量。
