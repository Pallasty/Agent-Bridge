# FH-L8 D29：D27 签名审批与资源收据验签器

D29 固定了可执行前唯一接受的六文件 bundle：两份原始 UTF-8 JSON、各自的 Ed25519 detached signature 和公钥。它使用 OpenSSL 对原始字节验签，拒绝额外/缺失/符号链接文件、重复 JSON key、非 Ed25519 key、请求或资源范围漂移。资源收据必须为该一次微型动作保留至少 D23 的 scratch 容量与 inode，并精确匹配 512 MiB、零 swap、180 秒。

验签成功只把**合成单次**动作标为可执行；它仍不读 q3、不调用内核、不授权 full-53。下一门才是隔离单次动作及测量收据。
