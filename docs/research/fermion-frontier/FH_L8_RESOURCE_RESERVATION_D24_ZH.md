# FH-L8 D24：外部资源预留收据契约

## 结论

`NO_GO_D24_EXTERNAL_RESOURCE_RECEIPT_ABSENT`。D24 冻结了可接纳的独立资源收据格式，但没有、也不伪造任何外部收据。

收据必须提供发放方、不可变哈希、专属执行槽与隔离标识、有效时间窗、scratch 可用字节与 inode、内存上限及运行时上限。其磁盘与文件数至少覆盖 D23 的 2,750,812,950 bytes / 13,622 files guardrail。

即使一份收据结构上可接纳，也不能自动授权：D23 的内存和运行时需求本身尚未被证明。D24 因此将“收据可接纳”与“科学执行可授权”严格分开。

## 下一门

证明 full 53-shard 的内存与运行时需求，并由独立方验证与该需求相符的资源收据。在此之前仍不得读取真实 q3 或运行科学核。
