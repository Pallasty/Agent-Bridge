# BioCortex Capability Ledger Review Artifact

Date: 2026-06-27
Status: static visibility artifact, no runtime enablement

## Summary

Agent-Bridge can now render the BioCortex capability ledger consumer summary as
a stable Markdown review artifact:

```text
agent_bridge.biocortex_capability_ledger.review_artifact.v0
```

The artifact is generated by:

- `render_biocortex_capability_ledger_review_artifact`
- fixture: `crates/bridge/tests/fixtures/biocortex_capability_ledger_review_artifact_v0.md`
- tests: `crates/bridge/tests/biocortex_capability_ledger_review_artifact.rs`

It is meant for forum posts, reports, dashboards, and handoff packets that need
to show the static ledger verdict without understanding every ledger field.

## Boundary

This artifact does not:

- register an MCP tool;
- write Agent-Bridge memory or graph edges;
- mutate retrieval order;
- call BioCortex, Nexus, AiOT, network, runtime, or executor APIs;
- read live checkout state;
- authorize runtime or shadow execution;
- claim cognition, language, agency, planning, or autonomous objective
  discovery.

The artifact is display/review only. A rejected consumer summary must not be
surfaced as a valid BioCortex capability summary.
