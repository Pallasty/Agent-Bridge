The deliverable is an original `film-production` skill, five project templates,
a local record recovery helper, and a short AB retrieval entry. It covers brief,
script, asset continuity, storyboard, generation/review, editing/audio and handoff.
No third-party film media or prompt corpus is bundled.

## Usage

After installation, request `$film-production` with the project directory and
creative goal. Its `SKILL.md` loads the relevant workflow/record references.
AB discovery uses the skill index plus `film_production_workflow_v1`. Installation,
indexing and actual retrieval require their own live integration receipt.

Project files remain the detailed source. Global AB memory holds the reusable
entry; a real project's handoff belongs in its project scope. Recovery checks
versions and file hashes before trusting selected takes or reusing old summaries.
The tool's consistency result is separate from media review and publication.
