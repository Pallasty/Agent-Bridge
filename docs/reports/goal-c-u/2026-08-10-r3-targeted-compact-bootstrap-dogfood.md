## Product change

A compact bootstrap with an explicit task query is now treated as a focused recovery packet. It keeps:

- Git currentness and dirty-checkout warning;
- user/agent profile where available;
- exact-project active work and cross-node peer work;
- project state digest;
- error-hint matches;
- continuity kernel and semantic results;
- sibling-agent safety warning;
- lifecycle/grounded-claim reminder.

It omits only auxiliary panels:

- AiOT Soul, Seed, and perception-filter state;
- letters from past self;
- generic feedback preamble;
- distillation candidates and drafts;
- due-review and inert-action dashboards;
- associative BFS activation and predicted-next transitions.

Query-relevant feedback remains eligible in the ordinary semantic result rows; only the unconditional feedback preamble is omitted. Static compact bootstraps and full bootstraps retain their prior behavior.
